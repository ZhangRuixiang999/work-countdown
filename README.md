# 牛马续航（窝囊版）

一个单文件的上班倒计时 + 摸鱼提醒面板，双击 `index.html` 就能用，不需要装任何东西、不联网。

## 页面布局

- **顶部主卡片**：左边是状态、距离下班倒计时、工时进度；右边是「今日完成进度」和喝水 / 起身 / 咖啡 / 拉粑四项进度条。
- **中间四张卡**：喝水提醒、久坐提醒、咖啡续命、带薪拉粑。
- **下面七张卡**：第一行「此刻心情、心愿清单、近期盼头、牛马关怀」，第二行「蓄谋寻坑、今日功德、最近的数据」。
- **设置**收在右上角齿轮里，从右侧滑出，点遮罩、✕ 或按 Esc 关闭。
- **迷你模式**：点标题栏的 📌 按钮，整页缩成屏幕右下角的小卡片（只留倒计时和工时进度），方便放屏幕一角随时瞄一眼；点小卡右上角的 ✕ 还原。

## 打卡与工时

只需要设置**每天工时**（默认 8 小时）和今天的打卡时间，下班时间自动算。

- 午休**不计入**工时（默认）：9:30 打卡、午休 12:00-13:00，18:30 下班。
- 打开「午休计入工时」：9:30 打卡、工时 8 小时，17:30 下班，午休那小时也算在工时里。

页面不再显示工资，只显示工时进度和各项完成情况。

## 今日完成进度

右侧的大数字是四项进度的平均值，下面分别列出：

- 喝水：今日饮水量 ÷ 饮水目标（默认 2000ml）
- 起身：起身次数 ÷ 起身目标（默认 6 次）
- 咖啡：今日总杯数 ÷ 咖啡目标（默认 1 杯）
- 拉粑：拉粑次数 ÷ 目标（默认 2 次）

目标都可以在设置里改。

## 各个卡片

- **喝水**：一杯 250ml，按目标显示 ml 和进度，到间隔时间（默认 30 分钟）提醒。
- **久坐**：显示已经坐了多久，到间隔（默认 45 分钟）提醒起身，点「起身活动了」重新计时并计一次。
- **咖啡续命**：默认一杯咖啡（每杯 80mg），可以点「＋ 添加一种饮品」自己加奶茶、可乐这些，填名字和咖啡因含量就能记。卡片按总杯数算进度，按咖啡因总量算进度条，超过 400mg 进度条变红并提示。
- **带薪拉粑**：记录次数，每趟按 10 分钟算「带薪摸鱼时长」，默认每 90 分钟提醒一次。
- **此刻心情**：五档表情（快碎了 / 有点累 / 还活着 / 挺不错 / 牛气冲天）。点一下记下「这一刻」，再在输入框补一句备注点「记下」（或直接回车）提交。点「回顾最近的心情」展开最近 40 条记录，每条都能单独删除。
- **心愿清单**：只记「想要什么」和「多少米」，下面大字显示金额。
- **近期盼头**：填「要去干嘛」和「什么时候」，实时倒计时到那个时刻。
- **蓄谋寻坑**：记录今天刷到几个岗位、投了几份简历。
- **今日功德**：摸鱼时敲一下攒功德，配默认木鱼音效和随机功德文案，数字会轻轻弹一下。
- **最近的数据**：支持切换回顾周期（7 天 / 14 天 / 30 天），每天显示喝水 / 起身 / 咖啡 / 拉粑 / 功德的计数。心情列不再只显示最近一条——同一天记过几次心情就显示几个表情，鼠标悬停还能看到当天每条心情的时间和备注。
- **牛马关怀**：随机一句安慰，点「换一句安慰」换下一条。

## 提醒音效

四个提醒都能单独选音效（叮咚 / 水滴 / 泡泡 / 铃铛 / 闷声 / 木鱼 / 静音），在设置里改，选完会立即试听。今日功德的敲击默认用木鱼音。总开关关掉后所有提示声音静音。

所有音效都是用浏览器实时合成的声音，不需要外部音频文件。

## 外观（黑白切换 + 自定义背景）

- **浅色主题**：点标题右边的 🌙 / ☀️ 按钮一键切深色 / 浅色，或者到设置 → 外观里勾选「浅色主题」。
- **背景**：设置 → 外观里可以选 5 种预设背景（默认夜色 / 极光绿 / 深海蓝 / 落日橙 / 纯色极简）。
- **自定义背景图片**：上传一张图（建议 800KB 以内）或填一个图片链接，图片会作为半透明背景铺在页面后面，只存在本机浏览器。「移除背景图片」一键还原。

## 其他

- 数据存在本机浏览器，跨过零点会自动重置当天的计数。
- 改了打卡时间，提醒计时会从新的打卡时间重新开始。
- 页面标题栏也会显示倒计时。
- 到达下班时间后显示 🎉 已下班。
- 心情记录会单独保存，不受跨零点重置影响；心愿和盼头也一直保留到你自己改掉；自己加的饮品类型也一样保留。
