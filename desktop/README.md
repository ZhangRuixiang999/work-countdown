# 牛马续航小窗（macOS）

真正透明的桌面悬浮倒计时：没有窗口边框、没有白底，数字直接浮在壁纸上，比浏览器画中画那个「带网址标题栏的小窗」干净得多。

数据从网页版同步过来，只走本机回环地址 `127.0.0.1:47821`，不上传任何服务器。小窗自己不存数据，**网页版得在浏览器里开着**（可以最小化、切到后台），它才会每 2 秒把倒计时推过来。

## 用法

1. 首次使用先编译（需要 macOS 命令行工具）：

   ```bash
   cd desktop
   ./build.sh
   ```

   编译完成后当前目录会出现 `牛马续航小窗.app`，它是**通用二进制**（Apple 芯片和 Intel 都能跑）。

2. 双击 `牛马续航小窗.app`。菜单栏出现沙漏图标，屏幕右上角出现透明小窗。

3. 第一次打开时，如果 6 秒内没有收到数据，App 会自动帮你打开一次网页版；之后也可以点小窗上的「打开网页版 →」。网页会在 2 秒内把倒计时、今日进度、喝水 / 起身 / 拉粑 / 功德同步到小窗。

4. 小窗弹出提醒时（喝水 / 起身 / 拉粑），可以直接点小窗上的「已完成」或「忽略」，网页里的计数和提醒会同步。

> 小窗没有边框，按住文字区域拖动即可。双击小窗在「完整」和「小条」之间切换。

小窗上显示「还没同步」和一排横线时，就是浏览器里还没有网页版在跑 —— 点一下卡片上的白色按钮即可。

网页右上角的 **📌** 按钮可以直接遥控这个小窗：点一下叫出来（并置顶），再点一下收起。如果 App 没开，📌 会退回到「把网页缩成页面小卡片」。

小窗自己的右上角还有两颗按钮：

- **🧘 功德 +1**：点一下今天功德加一，数字会弹一下，网页里的功德同步更新（网页开着才生效）。
- **↗ 打开网页**：用默认浏览器打开网页版。

底部四个数字：💧 显示的是今天的饮水量（毫升 / 目标毫升，比如 `250/2000 ml`），后面依次是起身次数、拉粑次数、今日功德。

右键小窗，或点菜单栏沙漏：

- **收起成小条**：缩成一条只显示倒计时和进度百分比，并自动贴到屏幕右侧。
- **贴到屏幕右侧**：把窗口贴到当前屏幕右边缘。
- **磨砂玻璃背景**：给文字加一层深色毛玻璃，壁纸太花时更好读；默认完全透明。
- **鼠标穿透**：小窗不拦鼠标，适合放在角落当摆件；再点一次恢复。
- **打开牛马续航网页**：浏览器打开网页版。
- **退出**：关掉 App。

## 透明是怎么做到的

macOS 上没有「让网页变透明」的开关，浏览器窗口的底色由浏览器控制（所以画中画小窗永远是深色或白色底）。真正透明要靠一个自己的窗口：

1. `NSWindow` 用 `.borderless`，再设 `isOpaque = false`、`backgroundColor = .clear`、`hasShadow = false`，窗口本身就没有背景。
2. 窗口层级设 `level = .floating`，配合 `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`，让它浮在所有窗口之上、切换桌面也跟着。
3. 里面放一个 `WKWebView`，用 `setValue(false, forKey: "drawsBackground")` 关掉网页白底，再把 `underPageBackgroundColor` 设成透明；网页侧 `html, body { background: transparent }`。
4. 文字为了在任意壁纸上都能看清，用 `text-shadow` 描一圈黑边（`body.clear` 那套样式）。
5. 想要毛玻璃就叠一层 `NSVisualEffectView`（`.hudWindow` + `.behindWindow`）。

## 数据同步

- App 在 `http://127.0.0.1:47821/` 上托管一份打包进去的网页（`Contents/Resources/index.html`，`build.sh` 从仓库根目录的 `index.html` 复制）。小窗的「打开网页」打开的就是这个地址。
- 为什么不用线上 GitHub Pages 版：https 页面去请求 `http://127.0.0.1` 时，Safari 会当成混合内容直接拦掉，Chrome 142+ 要用户点「允许访问本地网络」，公司网络还可能打不开 github.io。本机版网页和同步接口同源，这些限制都不存在。
- 网页每 2 秒 `POST /state`，带 `sourceId`（区分多个标签页）和当前状态；小窗回复里可以带 `actions`（比如 `["merit_add", "water_done"]`），网页收到后按顺序执行。
- 网页同时挂着一条长轮询 `GET /wait?source=<sourceId>`：小窗里一点功德 / 已完成，App 立刻回复这条请求，网页马上执行。这样网页标签页在后台、定时器被浏览器节流到一分钟一次时，点击也能立刻生效。连点几次功德会排队，一次都不会丢。
- 倒计时由小窗本地按上下班时间计算，就算浏览器标签页被后台节流也不会卡住。
- 关掉 App 后网页会自动降低重试频率（12 秒一次），重新打开 App 会自己接上。
- 多个标签页同时开着时，小窗只显示其中一个，点击也只发给它；新切到前台的标签页会接管。最好只留一个网页标签页。
- 本机版和线上版是两个网址，浏览器里的数据各存各的。

线上版（github.io）仍然会尝试同步，在 Chrome / Firefox 里允许后也能用；Safari 只能用本机版。

## 开机自启

系统设置 → 通用 → 登录项 → 添加 `牛马续航小窗.app`。

## 打包发给别人

```bash
cd desktop
./package.sh
```

会重新编译通用二进制，并生成可直接发送的 `牛马续航小窗-mac.zip`（约 120KB）。解压后是一层「牛马续航小窗」文件夹，里面有 `.app` 和 `安装说明.txt`。

对方安装推荐用终端一键装（脚本是仓库里的 `download/install.sh`）：

```bash
curl -fsSL https://zhangruixiang999.github.io/work-countdown/download/install.sh | bash
```

为什么：App 只有个人签名（`adhoc`），没有 Apple 公证。浏览器下载的文件带「来自互联网」标记，macOS 15 起 Gatekeeper 直接拦，「右键 → 打开」也不再能绕过；App 起不来，`127.0.0.1:47821` 的网页自然也打不开。`curl` 下载不会带这个标记。

如果对方已经用浏览器下了 zip，解压拖进「应用程序」后跑一句：

```bash
xattr -dr com.apple.quarantine "/Applications/牛马续航小窗.app"
```

需要注意的两点：

- zip 一定要用 `ditto` 打（`package.sh` 已经这么做了），换用普通压缩工具可能丢执行权限或弄坏签名。
- 网页已经打包进 App，对方不需要能访问 GitHub Pages。改了 `index.html` 之后要重新跑 `package.sh`，安装包里的网页才会更新。
